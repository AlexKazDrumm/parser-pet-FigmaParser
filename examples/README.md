# Пример экспорта

`demo_figma_file.json` содержит дерево узлов карточки входа с полями электронной
почты, пароля и кнопкой отправки формы.

Для узла `10:2` сохранены результаты структурного экспорта:

- `demo_output.html` — разметка;
- `demo_output.css` — стили;
- `demo_output.json` — сокращённое дерево узлов;
- `demo_preview.html` — страница предпросмотра.

Пересборка файлов:

```powershell
python examples/render_demo.py
```
